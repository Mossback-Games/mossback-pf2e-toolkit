# Changelog

## 0.1.0 (2026-11-23)

First release. Requires Foundry VTT v14 and the PF2E system 8.7 or later.

- Module skeleton: manifest, macro compendium build, release workflow.
- Added **Selected Tokens Report** macro.
- Added **Recall Knowledge** macro.
- Added runtime automation (`automation/`), shipped in the release package.
- Added **Background Lores** automation: a background's Lore skills are added to the character, trained, and removed with the background. World setting to turn it off.
- Added **Add Background Lores** macro, for characters that had a background before the toolkit was installed.
